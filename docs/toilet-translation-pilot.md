# 화장실 영어 번역 1,000건 시험 계획

## 목적

운영 전체 데이터를 번역하기 전에 시설명·도로명 주소·지번 주소·개방시간의 번역 품질, 재현성, 비용을 확인한다. 한국어 원본과 운영 DB는 변경하지 않고 시험 결과를 별도 파일 또는 격리 DB에 저장한다.

## 표본

- 수도권·광역시·도 지역을 층화하고 시·군·구별 편중을 제한한다.
- 역·공항·관광지·공원·공공청사·시장·학교·병원·상가 등 시설 유형을 포함한다.
- 괄호, 층·동·호, 숫자, 고유명사, 장문 이름과 주소 누락 사례를 의도적으로 포함한다.
- 1,000건 ID 목록과 원문 해시를 고정해 공급자나 프롬프트 변경 전후를 같은 표본으로 비교한다.

## 품질 판정

- 시설 고유명사·층·건물 구분·숫자를 보존한다.
- 도로명·지번 주소는 행정구역과 번지를 누락하거나 임의 변환하지 않는다.
- `24시간`, 요일별 시간, 상시·정시 등 개방시간의 의미를 유지한다.
- 원문에 없는 접근성·운영 정보를 생성하지 않는다.
- 자동 검사로 공란·숫자 손실·괄호 불일치·길이 초과를 찾고, 사람이 최소 100건을 층화 검수한다.
- 오류 유형과 수정 규칙을 기록하며 검수 완료 전 `REVIEWED`로 표시하지 않는다.

## 실행 경계

- 공급자별 예상 호출량·문자 수·최대 비용을 산출하고 사용자 승인 뒤 호출한다.
- 요청에는 다국어 대상 문자열과 내부 시험 ID만 포함하며 회원·리뷰·제보 데이터는 포함하지 않는다.
- 재시도 횟수와 동시 요청 수를 제한하고 예산 한도 도달 시 중단한다.
- 관리자 수동 번역은 자동 재실행으로 덮어쓰지 않는다.
- 합격 기준과 공급자를 확정하기 전 운영 DB·API·캐시에 반영하지 않는다.
